# [Ops] Weekly Approval Queue

## 사용 방법

이 페이지는 자동 루틴이 즉시 반영할 수 없는 Wiki 작업 후보를 한 곳에서 관리합니다.

처리 순서:
1. `playbook` 또는 `weekly`가 승인 필요 항목을 `활성 큐` 표에 추가합니다.
2. 담당자는 `상태`, `승인자`, `승인일`, `메모`를 입력합니다.
3. 다음 `weekly` 실행 시 `approved` 항목만 자동 처리합니다.
4. 처리 성공 시 `weekly`가 상태를 `done`으로 변경합니다.
5. 오래된 `done`/`rejected` 항목은 같은 페이지 하단 `History`로 이동합니다.

주의:
- 빈 상태는 신규 등록 후 아직 사람이 검토하지 않은 상태입니다.
- `pending`은 검토 중입니다.
- `approved`는 다음 weekly에서 자동 처리 가능함을 의미합니다.
- `rejected`는 현재 자동 처리하지 않음을 의미합니다.
- `done`은 weekly가 실제 반영까지 완료했음을 의미합니다.

## 상태 범례

| 상태 | 의미 | 누가 설정 |
|---|---|---|
| `pending` | 검토 필요. 아직 승인/반려 안 됨 | 담당자 |
| `approved` | 다음 weekly에서 자동 처리 가능 | 담당자 |
| `rejected` | 자동 처리하지 않음 | 담당자 |
| `done` | weekly가 실제 반영 완료 | weekly |

빈 상태:
- 신규 자동 등록 직후 상태
- 아직 사람이 검토하지 않은 상태
- weekly는 빈 상태를 `pending`과 동일하게 처리하지 않음

## 자동 정리 규칙

- `done` 상태가 7일 지난 항목은 `History`로 이동합니다.
- `rejected` 상태가 14일 지난 항목은 `History`로 이동합니다.
- `pending` 상태가 7일 이상 유지되면 weekly 런 리포트에 stale pending 경고를 남깁니다.
- `approved` 상태는 weekly가 실제 처리하기 전까지 `활성 큐`에 유지합니다.
