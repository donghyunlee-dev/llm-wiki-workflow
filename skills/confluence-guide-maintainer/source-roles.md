# Source Rules

## Source Priority

Use sources in this order:

1. Official product documentation
2. Official GitHub repository
3. Official release notes
4. Official blog
5. Package registry page
6. Vendor community or forum
7. Trusted technical blog
8. Community post

## Automatic Update Threshold

Automatic updates are allowed only when the change is supported by official or highly trusted sources.

## Source Trust Levels

- OFFICIAL_DOCS: high
- OFFICIAL_GITHUB_RELEASE: high
- OFFICIAL_BLOG: high
- PACKAGE_REGISTRY: medium-high
- VENDOR_FORUM: medium
- TECH_BLOG: medium-low
- COMMUNITY_POST: low
- UNKNOWN: low

## Web Search Rules

When searching the web:

- Prefer official domains.
- Prefer recent documentation for actively changing tools.
- Compare publication or update dates.
- Do not use stale blog posts as the primary source.
- Do not treat SEO articles as authoritative.
- Record source URLs in the run report.

## Conflict Rule

If official sources conflict, do not update automatically.

Create a manual review item with:

- Conflicting source URLs
- Summary of conflict
- Recommended human decision
